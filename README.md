# 국수집 (GuksuJip)

블록으로 쌓은 3D 국숫집에 들어가 메뉴를 고르면, 주인장이 국수를 내오면서 프로젝트를 소개하는 포트폴리오 사이트입니다.

**[→ 사이트 열기](https://guksu.github.io/GuksuJip/)**

## 화면 흐름

1. 첫 화면은 밤거리의 가게 앞에 얹은 타이틀 화면입니다. '가게 들어가기'를 고르거나 문을 누르면 천이 걷히고 카메라가 가게 안으로 들어갑니다.
2. 카운터 뒤의 주인장이 인사하고 차림표를 건넵니다.
3. 차림표에서 메뉴를 고르면 주인장이 "잠시만요!" 하고 돌아서서 국수를 삶습니다.
4. 그릇이 카운터에 놓이면 카메라가 그릇으로 다가가고, 옆에 프로젝트 소개가 펼쳐집니다. 그릇의 국물 색과 고명은 프로젝트마다 다릅니다.
5. 차림표로 돌아오면 맛본 그릇이 카운터 한쪽에 작게 남습니다. 한 그릇이라도 맛보면 차림표 아래에 계산서가 생기고, 계산서는 연락처로 이어집니다.

메뉴마다 주소가 있어서 `…/GuksuJip/#/menu/suta`처럼 바로 공유할 수 있습니다. 메뉴 주소로 들어오면 가게 앞과 조리 장면을 건너뛰고 음식부터 보여 줍니다. 맛본 메뉴는 저장하지 않아서, 다시 들어오면 가게 앞에서 새로 시작합니다.

## 구현하면서 신경 쓴 것

- **픽셀로 보이는 3D**: three.js로 상자를 쌓아 가게, 주인장, 그릇을 만들었습니다. 모델 파일 없이 전부 코드로 쌓습니다. 화면을 실제 크기의 1/3로 그린 뒤 늘려서 픽셀이 보이게 했습니다.
- **장면과 화면 UI의 분리**: 3D 장면(`src/scene`)은 "들어가라, 이 메뉴를 내라" 같은 명령만 받고, 차림표와 소개 같은 글은 React가 그 위에 얹습니다. 명령은 한 번에 하나씩 차례로 처리하고, 명령이 밀리면 앞의 연출을 빨리 감습니다.
- **기다림 건너뛰기**: 입장, 인사, 조리 장면은 화면을 누르거나 '건너뛰기'를 누르면 빨리 넘어갑니다.
- **소리**: 효과음과 배경음은 소리 파일 없이 Web Audio로 만듭니다. 기본은 꺼져 있고, 타이틀 화면이나 화면 왼쪽 위에서 켭니다.
- **용량**: three.js가 들어간 장면 코드는 따로 나눠서 내려받습니다.
- **키보드와 스크린 리더**: 가게에 들어가기, 메뉴 고르기, 차림표로 돌아가기는 모두 버튼이고, 화면이 바뀌면 포커스가 차림표나 소개 제목으로 옮겨 갑니다. 주인장의 말은 스크린 리더로도 읽어 줍니다. 소개 화면에서 Esc를 누르면 차림표로 돌아갑니다.
- **동작 줄이기**: 기기에서 동작 줄이기를 켜면 카메라 이동과 조리 장면 없이 화면만 바뀝니다.
- **3D를 못 쓰는 브라우저**: WebGL을 쓸 수 없으면 장면 없이 차림표와 소개만 보여 줍니다.

## 메뉴 고치기

| 고칠 것 | 파일 |
|---|---|
| 프로젝트 추가·수정(이름, 소개, 주요 기능, 사용 기술, 링크, 국물 색과 고명) | `src/data/menu.ts` |
| 제품 화면 이미지 | `src/assets/shots/{메뉴}/`에 넣고 `src/data/shots.ts`에 등록 |
| 주인장 정보(이름, 한 줄 소개, 깃허브, 이메일) | `src/data/owner.ts` |
| 가게, 주인장, 그릇의 모양 | `src/scene/world.ts` |
| 주인장의 말과 연출 순서 | `src/scene/stage.ts` |
| 색·글꼴·간격 | `src/styles/tokens.css` |

제품 화면은 세 가지에서 가져왔습니다. 앱은 스토어 소개 이미지, 웹은 실제 사이트를 캡처한 화면, 나머지는 각 저장소 README의 이미지입니다. 화면이 없는 CLI와 스킬은 README에 있는 터미널 출력을 글자로 넣었습니다.

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5290/GuksuJip/
npm test           # 메뉴 데이터, 주소 규칙 검사
npm run build      # 타입 검사 후 dist/에 빌드
```

## 구조

```
src/
├ App.tsx                  주소와 가게 화면 연결
├ data/menu.ts             메뉴(프로젝트) 데이터
├ data/shots.ts            제품 화면 목록
├ data/owner.ts            주인장 정보
├ hooks/useHashRoute.ts    #/menu/{이름} 주소
├ hooks/useOrdered.ts      이번 방문에서 맛본 메뉴
├ lib/sound.ts             효과음과 배경음
├ scene/
│ ├ stage.ts               장면 진행(입장, 인사, 조리, 내기)과 카메라
│ ├ world.ts               가게 밖·안, 주인장, 그릇 모델
│ ├ vox.ts                 상자를 쌓아 메시로 묶는 도구
│ └ tweens.ts              움직임 시간 관리
├ components/
│ ├ Shop.tsx               장면 위에 얹는 화면(안내, 말풍선)
│ ├ TitleScreen.tsx        타이틀 화면
│ ├ MenuPanel.tsx          차림표
│ ├ DetailPanel.tsx        소개 패널
│ ├ ProjectSheet.tsx       소개 본문
│ ├ Shots.tsx              제품 화면과 터미널 출력
│ └ CheckDialog.tsx        계산서
└ styles/                  색·글꼴·간격 변수와 기본 스타일
```

Vite, React, TypeScript, CSS Modules, three.js로 만들었습니다. 글꼴은 Pretendard와 픽셀 글꼴 Galmuri11입니다.

## 배포

`main`에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 올립니다. 저장소 이름을 바꾸면 `vite.config.ts`의 `base`도 함께 바꿔야 합니다.
