# 국수집 (GuksuJip)

옆에서 본 픽셀 국숫집에 들어가 오늘의 차림에서 국수를 주문하면, 주인장이 국수를 만들어 내오면서 프로젝트를 소개하는 포트폴리오 사이트입니다. 게임처럼 둘러보게 만들었습니다.

**[→ 사이트 열기](https://guksu.github.io/GuksuJip/)**

## 화면 흐름

1. 첫 화면은 눈 내리는 밤의 가게 앞에 얹은 타이틀 화면입니다. '가게 들어가기'를 고르거나 문을 누르면 막이 닫혔다 열리며 가게 안으로 들어갑니다.
2. 카운터 뒤의 주인장이 인사하고 '오늘의 차림'을 엽니다. 왼쪽에서 국수를 고르면 오른쪽 카드에 그 프로젝트의 이름, 한 줄 소개, 분류, 재료(사용 기술)가 나옵니다.
3. 주문하면 국수를 만드는 장면이 이어집니다. 세 컷과 완성 컷으로 이루어지고, 국수에 따라 장면이 다릅니다. 따뜻한 국물 국수는 삶고 썰어 담고, 차게 먹는 국수는 삶아서 찬물에 헹구고, 짬뽕과 짜장면은 센 불에 볶습니다. 건너뛸 수 있습니다.
4. 그릇이 카운터에 놓이면 옆에 프로젝트 소개가 펼쳐집니다. 그릇의 국물 색과 고명은 프로젝트마다 다릅니다.
5. 맛본 국수는 벽의 차림 쪽지에 표시가 찍히고, 빈 그릇이 카운터 한쪽에 쌓입니다. 화면 위에는 맛본 그릇 수와 지금 할 일이 늘 보입니다. 한 그릇이라도 맛보면 계산서가 생기고, 계산서는 연락처로 이어집니다.

메뉴마다 주소가 있어서 `…/GuksuJip/#/menu/suta`처럼 바로 공유할 수 있습니다. 메뉴 주소로 들어오면 가게 앞과 만드는 장면을 건너뛰고 음식부터 보여 줍니다. 맛본 메뉴는 저장하지 않아서, 다시 들어오면 가게 앞에서 새로 시작합니다.

## 구현하면서 신경 쓴 것

- **코드로 그린 픽셀 그림**: 가게, 주인장, 손님, 국수 그릇을 그림 파일 없이 캔버스에 칸 단위로 그립니다. 그린 뒤 바깥선을 자동으로 둘러서 그림체를 맞췄습니다. 화면은 작게 그린 뒤 정수배로 늘려서 픽셀이 보이게 했습니다.
- **간판 글씨**: 픽셀 글꼴을 작은 크기로 바로 그리면 획이 흐려져 끊깁니다. 네 배로 크게 그린 뒤 칸 가운데만 읽어서 또렷한 글씨를 얻습니다.
- **같은 그릇**: 차림의 그릇 그림, 만드는 장면의 그릇, 카운터에 놓이는 그릇은 모두 같은 그림 코드에서 나옵니다. 메뉴 데이터의 국물 색과 고명을 바꾸면 세 곳이 함께 바뀝니다.
- **장면과 화면 UI의 분리**: 장면(`src/pixel`)은 "들어가라, 이 메뉴를 내라" 같은 명령만 받고, 차림과 소개 같은 글은 React가 그 위에 얹습니다. 차림이나 소개가 열리면 패널이 가린 만큼 장면을 비켜 놓아서 주인장이 계속 보입니다.
- **색**: 먹색, 종이색, 나무색에 노렌과 앞치마의 남색 하나만 강조로 씁니다.
- **기다림 건너뛰기**: 입장, 인사, 만드는 장면은 화면을 누르거나 '건너뛰기'를 누르면 바로 넘어갑니다.
- **소리**: 효과음과 배경음은 소리 파일 없이 Web Audio로 만듭니다. 기본은 꺼져 있고, 타이틀 화면이나 화면 위에서 켭니다.
- **키보드와 스크린 리더**: 차림은 위아래 화살표로 고르고 Enter로 주문합니다. 소개는 좌우 화살표로 앞뒤 국수를 넘기고 Esc로 차림에 돌아갑니다. 화면이 바뀌면 포커스가 차림이나 소개 제목으로 옮겨 가고, 주인장의 말은 스크린 리더로도 읽어 줍니다.
- **동작 줄이기**: 기기에서 동작 줄이기를 켜면 막과 만드는 장면 없이 화면만 바뀝니다.
- **장면을 못 띄우는 브라우저**: 캔버스를 쓸 수 없으면 장면 없이 차림과 소개만 보여 줍니다.

## 메뉴 고치기

| 고칠 것 | 파일 |
|---|---|
| 프로젝트 추가·수정(이름, 소개, 주요 기능, 사용 기술, 링크, 국물 색과 고명) | `src/data/menu.ts` |
| 제품 화면 이미지 | `src/assets/shots/{메뉴}/`에 넣고 `src/data/shots.ts`에 등록 |
| 주인장 정보(이름, 한 줄 소개, 깃허브, 이메일) | `src/data/owner.ts` |
| 가게, 주인장, 손님의 모양 | `src/pixel/shopart.ts` |
| 그릇과 고명의 모양 | `src/pixel/sprites.ts` |
| 주인장의 말, 연출 순서, 만드는 장면 | `src/pixel/stage.ts` |
| 국수마다의 만드는 방식 | `src/pixel/recipes.ts` |
| 색·글꼴·간격 | `src/styles/tokens.css` |

제품 화면은 세 가지에서 가져왔습니다. 앱은 스토어 소개 이미지, 웹은 실제 사이트를 캡처한 화면, 나머지는 각 저장소 README의 이미지입니다. 화면이 없는 CLI와 스킬은 README에 있는 터미널 출력을 글자로 넣었습니다.

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5290/GuksuJip/
npm test           # 메뉴 데이터, 주소 규칙 검사
npm run build      # 타입 검사 후 dist/에 빌드
```

## 구조

```
src/
├ App.tsx                  주소와 가게 화면 연결
├ data/menu.ts             메뉴(프로젝트) 데이터
├ data/shots.ts            제품 화면 목록
├ data/owner.ts            주인장 정보
├ hooks/useHashRoute.ts    #/menu/{이름} 주소
├ hooks/useOrdered.ts      이번 방문에서 맛본 메뉴
├ lib/sound.ts             효과음과 배경음
├ pixel/
│ ├ stage.ts               장면 진행(입장, 인사, 만드는 장면, 내기)과 그리는 순서
│ ├ recipes.ts             국수마다의 만드는 장면
│ ├ shopart.ts             가게 앞, 가게 안, 주인장, 손님 그림
│ ├ sprites.ts             국수 그릇과 고명, 고양이 그림
│ └ paint.ts               칸 단위로 그리고 바깥선을 두르는 도구
├ components/
│ ├ Shop.tsx               장면 위에 얹는 화면과 소리 연결
│ ├ Hud.tsx                맛본 그릇 수, 할 일, 새 국수 알림
│ ├ Dialogue.tsx           주인장 대화창
│ ├ TitleScreen.tsx        타이틀 화면
│ ├ MenuBoard.tsx          오늘의 차림(목록과 요리 카드)
│ ├ BowlIcon.tsx           국수 그릇 그림
│ ├ DetailPanel.tsx        소개 패널
│ ├ ProjectSheet.tsx       소개 본문
│ ├ Shots.tsx              제품 화면과 터미널 출력
│ └ CheckDialog.tsx        계산서
└ styles/                  색·글꼴·간격 변수와 기본 스타일
```

Vite, React, TypeScript, CSS Modules로 만들었고, 장면은 Canvas 2D로 그립니다. 글꼴은 Pretendard와 픽셀 글꼴 Galmuri11입니다.

## 배포

`main`에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 올립니다. 저장소 이름을 바꾸면 `vite.config.ts`의 `base`도 함께 바꿔야 합니다.
